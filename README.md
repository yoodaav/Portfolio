# Portfolio Nuit (moderne, FR / EN)

Portfolio de NFONRANGOU NJOYA Zakariaou. Bascule FR / EN dans la barre de navigation (le choix est mémorisé).

## Contenu
- `index.html` : structure de la page
- `style.css` : design (couleurs dans les variables `:root` en haut du fichier)
- `script.js` : textes FR/EN (objet `UI`), projets, compétences, parcours et animations
- `assets/` : photo et CV (`CV_Njoya.pdf`)

## Modifier le contenu
Les textes d'interface sont dans `UI` (fr / en) en haut de `script.js`. Les projets ont un bloc `fr` et un bloc `en`. Le CV reste en français.

## Mettre en ligne (GitHub Pages)
1. Envoyer tous les fichiers à la racine du dépôt.
2. Dans Settings > Pages, choisir la branche `main` et le dossier `/ (root)`.
